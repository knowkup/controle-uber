# Publicação

Este projeto é publicado exclusivamente pelo GitHub Pages em:
`https://knowkup.github.io/controle-uber/`

Para colocar alterações em produção, envie o commit da branch `main` para
`origin` (`https://github.com/knowkup/controle-uber.git`) e confira a URL
pública. Não use Firebase Hosting para publicar este projeto.
